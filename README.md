# Olympus Mons: The Voyage | README / Introduction

## Introduction (Or a summary if you are in a rush)

This game is Olympus Mons: The Voyage, a simulator game where people can explore the vast landscape of Olympus Mons, the biggest mountain in the Solar System, which happens to be on Mars. The objective of the game is to reach the summit, the Caldera, from your spawn, which is a few kilometers away. I made this project because I want more people to see the beauty of the planets in the Solar System. If people get interested in Mars and the Solar System after playing the game, then my goal with this game is fulfilled.

## Why I made the project

So, hi there. This is a project to help more people appreciate the beauty of Mars, a planet which I have found amazing with its beautiful desert-like structures and vast landscape. I am really fascinated with space and what's out there, and Mars is one of the main reasons. Out of all the planets, I find Mars the most likely candidate to allow humans to become an interplanetary species. So, all these reasons are what make me want to make a game that can spark an interest in outer space and other planets in everybody.

## About the star of the show (Olympus Mons)

The project is based on Olympus Mons, a huge mountain on Mars that is arguably the tallest mountain in the Solar System, probably the tallest physical structure on another planet that we know of. It's about 20 km tall and 600 km wide. You might be surprised considering its width. I mean, the mountains I drew in kindergarten were way less wide than they were tall (very pointy triangles, in fact). Olympus Mons is also not as steep as a stereotypical mountain. If you stood on Olympus Mons, it would appear as a very smooth, gradual plain slowly increasing in height; it wouldn't even have been hard to walk to the summit, Caldera (forgetting the 300 km "walk"), and you probably could barely see the slope anyway.

## 3D Models

Alright, so the project's name is Olympus Mons: The Voyage... I'm planning to make more polished sequels; this is just a test run... The Olympus Mons model was obtained using MOLA elevation data from NASA. MOLA data is a data repository from satellites that includes maps like DEMs (Digital Elevation Models, which I had used), geological maps, etc. The DEM, after some struggle, was found after surfing the web way too much and getting into websites a bit too sketchy for my liking; I had found the DEMs... I imported them into Blender, turned the DEM into an actual 3D model, and imported it into Unity. As for the rover, I made it by myself in Blender... Which wasn't easy considering I had started to learn Blender specifically for this project. So, the rover is probably not the best model you can find. The rover is actually based on an actual concept of a Mars rover.

## Game's Main Objective

So, in the game, your main goal is to drive a rover to Caldera... The summit of Olympus Mons, which will be a few kilometers away from spawn, while trying to control a high-speed rover in a low-gravity and low-traction environment... Martian regolith (the soil) is known to be very loose. I might add an option to glide, but that is very unrealistic considering Mars's thin atmosphere.
